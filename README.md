# Projeto-Java---Gestao-Laboratorios-Cientificos

Este projeto foi desenvolvido no âmbito da unidade curricular Programação com Objetos (2025/2026) e consiste na implementação, em Java, de um sistema de gestão para uma rede de laboratórios científicos que realizam projetos de investigação nas áreas de Biotecnologia, Robótica e Energias Renováveis.

A aplicação segue os princípios fundamentais da programação orientada a objetos, com separação clara entre lógica de negócio e interface em modo de texto, organizadas em pacotes distintos. O sistema permite persistência de dados através de ficheiros, garantindo a recuperação do estado em sessões futuras.
